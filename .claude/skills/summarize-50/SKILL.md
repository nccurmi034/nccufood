# 50 字重點摘要

將使用者提供的文字濃縮成 **50 字以內** 的重點。

## 規則
1. 輸出語言與原文一致（中文原文以繁體中文輸出）。
2. 總字數（含標點）不得超過 50 字。
3. 保留核心主題、關鍵結論或數字，刪除背景、例子、修飾語。
4. 不加入原文沒有的資訊，不加評論。
5. 只輸出摘要本身，一段話，不加標題或前言。
6. 若原文過短（已少於 50 字），直接回覆原文並說明無需精簡。
7. 輸出前自行數字，超過 50 字就繼續精簡。

## 輸出格式
> 摘要內容（XX 字）
