# 訂單串接 Google Sheet 設定教學

結帳送出 → Apps Script Web App → 寫入 Google Sheet → 寄通知信。

## 一、建立試算表並貼上程式（約 5 分鐘）

1. 到 [Google Sheets](https://sheets.google.com) 建立一份新的空白試算表，命名為「金酥鍋貼訂單」。
2. 選單 **擴充功能 → Apps Script**。
3. 把 `Code.gs` 的全部內容貼進編輯器（取代原本的 `myFunction`）。
4. （建議）左側 **專案設定** → 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」，回到編輯器開啟 `appsscript.json`，貼上本資料夾同名檔案的內容。
5. 如果你想指定收通知信的信箱，把 `Code.gs` 最上方 `CFG.OWNER_EMAIL` 改成你的信箱（留空則用你自己的 Google 帳號信箱）。

## 二、初始化

1. 編輯器上方函式選單選 **`setup`** → 按 **執行**。
2. 第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→ 允許。（這是你自己寫的程式，會要求讀寫試算表與寄信權限。）
3. 回到試算表，會多出三個分頁：
   - **訂單**：一筆訂單一列，「狀態」欄有下拉選單。
   - **訂單明細**：每個品項一列。
   - **菜單**：品項與價格。**GAS 以這裡的價格為準**，要改價或下架（把「上架」改 FALSE）直接改這裡。

## 三、部署成網頁應用程式

1. 右上角 **部署 → 新增部署作業** → 類型選 **網頁應用程式**。
2. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
3. 按 **部署**，複製「網頁應用程式網址」（以 `/exec` 結尾）。
4. 用瀏覽器開這個網址，看到 `{"ok":true,...}` 代表部署成功。

## 四、接到網站

打開 `index.html`，找到：

```js
const SHEETS_ENDPOINT = '';
```

把網址貼進去：

```js
const SHEETS_ENDPOINT = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

存檔、推上 GitHub，等 Pages 更新後，到網站下一筆測試訂單，試算表就會出現資料。

> 也可以把 `/exec` 網址貼給 Claude，請它幫你改好並合併。

## 五、日常使用

| 想做的事 | 怎麼做 |
|---|---|
| 看新訂單 | 開「訂單」分頁；店家信箱也會收到【新訂單】通知信 |
| 通知顧客可以取餐 | 把該列「狀態」改成 **可取餐**，系統自動寄信給顧客（**已出貨** 同理） |
| 改價格／下架 | 改「菜單」分頁的價格或「上架」 |
| 新增菜單品項 | 「菜單」分頁新增一列（ID 不可重複），並在 `index.html` 的 `products` 加上同 ID 的品項 |

## 六、修改程式後要重新部署

改過 `Code.gs` 後，**部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**。網址不會變。

## 安全與限制

- 金額一律由 GAS 依「菜單」分頁重算，前端改價格無效。
- 以 `=` `+` `-` `@` 開頭的文字會自動加上單引號，避免試算表公式注入。
- 表單有隱藏的 honeypot 欄位擋簡單機器人；同時只處理一筆寫入（LockService），訂單編號不會重複。
- 一般 Google 帳號寄信上限約每天 100 封（顧客信＋店家信各算一封）。
- 網頁應用程式網址是公開的，任何人都能對它送資料，請不要在試算表放敏感資訊；若遭濫用，可在「管理部署作業」停用該部署。
- 前端的 `FREE_SHIP`／`SHIP_FEE` 與 `Code.gs` 的 `CFG` 需一致（實際金額以 GAS 為準）。

## 疑難排解

| 狀況 | 原因與處理 |
|---|---|
| 網站顯示「訂單送出失敗」 | 按 F12 → Console 看錯誤；確認 `SHEETS_ENDPOINT` 正確、部署的存取權是「所有人」 |
| 顯示「品項不存在或已下架」 | 「菜單」分頁沒有該 ID，或「上架」不是 TRUE |
| 訂單有寫入但沒收到信 | 看垃圾信件匣；或 Apps Script 左側「執行作業」查寄信錯誤 |
| 改了狀態卻沒寄信 | 重新執行一次 `setup` 建立觸發器；狀態只有「可取餐」「已出貨」會寄 |
| 改了程式沒生效 | 需要「新版本」重新部署（見第六點） |
